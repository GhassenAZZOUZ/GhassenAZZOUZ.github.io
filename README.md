# Ghassen Azouz — Portfolio

Personal portfolio of Ghassen Azouz, QA Automation Engineer based in Paris.

**Live:** https://ghassenazouz.vercel.app · https://ghassenazzouz.github.io/monportfolio/

## Stack

- React 19 + TypeScript
- Vite 6
- Vanilla CSS (no framework)

## Development

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # production build → dist/
npm run preview   # preview the production build locally
```

## Deployment

| Target | Trigger | URL |
|---|---|---|
| Vercel | push to `main` | ghassenazouz.vercel.app |
| GitHub Pages | push to `main` | ghassenazzouz.github.io/monportfolio/ |
| PR preview | open a PR → `main` | ghassenazzouz.github.io/pr-{n}/ |
